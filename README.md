# Ivy Homes Property Intelligence Dashboard

A full-stack property discovery and analytics dashboard built for the Ivy Homes internship assignment.

## Features

- Login and session handling
- Property listings
- Rentals listing
- Projects listing
- Listing detail page
- Saved/favourite listings
- Insights dashboard
- Pagination
- Search and filters
- Data quality analysis
- Responsive dashboard UI

## Tech Stack

- React
- Vite
- JavaScript
- CSS
- Python
- REST APIs
- LocalStorage for saved listings/session persistence

## Project Structure

- `frontend/` - React frontend
- `analysis/` - Data download and analysis scripts
- `submission.json` - Assignment answers
- `README.md` - Documentation

## Run Frontend

```bash
cd frontend
npm install
npm run dev
